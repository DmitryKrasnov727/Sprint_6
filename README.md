Курс по автоматизации тестирования на Python, «Яндекс Практикум».
Спринт 6, Page Object Model.

Корневая директория проекта содержит набор тестов и файлы со вспомогательными инструментами:

- в page_object файлы с классами для каждой тестируемой страницы;
- в tests лежат файлы с тестами;
- в locators локаторы, используемые в тестах;
- в conftest фикстуры;
- в data тестовые данные полей ввода;
- в allure_results результаты выполнения тестов;
- в requirements.txt внешние зависимости;
- в README общая инфа. 

Запуск всех тестов: `pytest -v`.

Allure-отчет `allure serve allure_results`.
